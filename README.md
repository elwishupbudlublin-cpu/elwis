# ELWIS – Elektryczne Wsparcie Instalatora i Serwisu

Aplikacja na tablety (PWA, Android) dla ekip AKPiA: podłączenia według listy urządzeń i rzutów, numery seryjne, braki, protokoły. Działa offline, synchronizuje się przez WiFi z Google Drive.

- `index.html`, `css/`, `js/`, `sw.js` – aplikacja (bez zależności, bez budowania)
- `apps-script/` – serwer synchronizacji (Google Apps Script)
- `docs/API.md` – opis API
- `INSTRUKCJA.md` – uruchomienie krok po kroku

Repozytorium nie zawiera danych budów, kluczy ani PIN-ów – wszystko jest w Bazie projektów na koncie ELWIS.
